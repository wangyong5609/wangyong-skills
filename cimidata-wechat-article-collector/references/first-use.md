# 首次使用引导

仅当用户说首次使用、开通、充值、没有凭据、配置失败，或 `status` 显示未设置时读取本文件。

## Agent 对用户的第一句话

```text
我来带你把次幂接好。你只需要完成三件事：在次幂后台开通服务、拿到 App ID 和 App Secret、确认一次小额试用预算。命令和配置文件由我处理。
```

先询问用户是否已有次幂账号。没有时，引导他们打开官方站点 `https://www.cimidata.com` 注册或登录；已有账号则直接进入 API/开发者相关页面。不要编造页面菜单、免费额度、套餐或充值金额。若用户找不到入口，请让他提供当前页面截图，再逐屏说明下一步。

## 三步流程

1. **在次幂后台开通接口并充值**：请用户只完成平台要求的注册、实名/企业信息（如有）、接口开通和充值。说明本 Skill 的首次试用可限制为不高于 ¥0.30；不要建议超出用户目标的充值额。
2. **取得凭据**：请用户在次幂的 API 凭据页创建或查看 App ID 与 App Secret。解释它们像账号密码，不能公开发送、截图分享或提交 GitHub。
3. **保存到本机并免费校验**：让用户采用一种方式即可：

   - **最简单**：在私密一对一对话中把 App ID 和 App Secret 交给 Agent。Agent 保存到 Skill 根目录的 `.env`：若 Skill 在 `<目录>/cimidata-wechat-article-collector/`，文件位于 `<目录>/cimidata-wechat-article-collector/.env`。
   - **自己保存**：用户将 Skill 根目录的 `.env.example` 复制为 `.env`，写入两行 `CIMIDATA_APP_ID=...` 与 `CIMIDATA_APP_SECRET=...`；也可直接设置同名环境变量。

   设置向导为：

   ```bash
   python3 scripts/cimidata_wechat.py setup
   ```

   向导会隐藏 Secret 输入、免费获取 token 验证凭据，再写入 Skill 根目录 `.env`。已配置时使用 `status --verify`；不要把凭据显示出来。Agent 收到私密凭据时也执行同样的“保存后免费校验”步骤，但最终回复只说明结果。

完成后，用自然语言告诉用户：“现在可以试采一篇”。不要要求他们自己找 `wxid`。

## 首次成功：最小可理解试用

优先级如下：

1. 用户有文章链接：只读取正文，预计 ¥0.01。
2. 用户只有公众号名称：搜索精确账号并采最近 1 篇正文，预计最多 ¥0.16。
3. 用户明确还要互动：在对应方案上再加 ¥0.03。

先展示范围、价格和输出位置，等待“确认”后执行。首次试用默认不取评论或图片；出现错误时不要重试付费接口，解释已停止并保留已成功内容。

## 常见情况

| 用户看到的情况 | 用普通语言解释 | Agent 的处理 |
| --- | --- | --- |
| token 校验失败 | “凭据可能复制错了，或接口尚未开通。” | 回到凭据页确认；不显示 Secret。 |
| 余额不足/权限不足 | “这个接口目前不能使用，请在次幂后台检查余额和开通状态。” | 停止；不改范围、不自动充值。 |
| 找到多个同名公众号 | “名称有重名，请确认头像、简介或微信号。” | 展示最多 5 个公开候选，等待选择。 |
| 文章已删除或正文为空 | “这篇文章当前无法读取。” | 停止该篇，报告可能已发生的单篇费用，不自动重试。 |
