# 第一次使用：AI 照着说

只在用户第一次使用、尚未配置、或配置失效时读取。本文件是 AI 的对话脚本，不是让用户阅读的技术说明。

## 一次只带一步

不要一次发一长串教程。每完成一步，等用户回复“好了”或发来截图，再说下一步。

### 第一步：注册

对用户说：

```text
第一次用要先注册次幂。打开 https://www.cimidata.com 注册并登录；弄好后告诉我“好了”。
```

### 第二步：打开密钥页面

用户说“好了”后，对用户说：

```text
现在打开这个页面：https://www.cimidata.com/api-service 。
```

### 第三步：创建密钥

用户打开页面后，对用户说：

```text
往下找到“API 密钥管理”，点“新增密钥”。
```

若用户找不到，就让他发当前页面截图；根据截图只说下一步该点哪里。

### 第四步：把两行内容发给 AI

成功弹窗出现后，对用户说：

```text
弹窗里有 AppID 和 Secret 两行内容。把这两行都复制发给我，我来保存。
```

不要解释后台技术细节。

## AI 收到 AppID 和 Secret 后

1. 立即更新 Skill 根目录的 `.env`，只写 `CIMIDATA_APP_ID` 与 `CIMIDATA_APP_SECRET`。
2. 免费校验 token。
3. 不回显这两个值，也不把它们写入日志、输出或 Git。
4. 只回复：

```text
好了，已经帮你存好了。现在告诉我你想采哪个公众号。
```

## 首次采集

用户说公众号名称后，对用户说：

```text
我先帮你采最近一篇正文，不采评论和图片。本次最多花 ¥0.16，可以吗？
```

用户确认后执行。若用户给的是文章链接，对用户说：

```text
这次只取这篇文章正文，最多花 ¥0.01，可以吗？
```
