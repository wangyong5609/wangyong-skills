# 次幂公众号数据

把技术步骤藏在 Agent 后面。默认用户不需要理解命令、`.env`、绝对路径、`wxid` 或 API 参数；他们只需要说明目标、在次幂后台完成开通/充值，以及确认一次花费。

它与 `wechat-article-collector` 完全独立：不要读取、修改或回退调用极致了/大加啦接口，也不要混用两套凭据。

## 面向普通用户的服务方式

先用自然语言确认目标。例如：

- “带我开通次幂，先试采一篇文章。”
- “采集 `某公众号` 最近一篇，先只要正文。”
- “这篇链接的阅读、点赞和在看是多少？”

不要先要求用户运行命令、寻找 `wxid` 或配置环境变量。除非用户主动要求技术细节，也不要直接展示脚本命令。

首次使用时，先执行 `status`。若尚未配置，读取 [首次使用引导](references/first-use.md)，按其中的三步带领用户完成：次幂后台开通、取得 App ID/App Secret、存到本机私有配置。不要猜测次幂后台的菜单名称；用户卡住时请索取当前页面截图后继续引导。

App Secret 是密码级信息：不在群聊、公开文档、GitHub、输出文件或最终回复中回显。凭据读取顺序固定且简单：先读环境变量 `CIMIDATA_APP_ID` 与 `CIMIDATA_APP_SECRET`；没有时再读 Skill 根目录的 `.env`。例如 Skill 在 `<目录>/cimidata-wechat-article-collector/`，凭据文件就是 `<目录>/cimidata-wechat-article-collector/.env`。Skill 内附 `.env.example`，用户可复制后填写。

用户可在私密一对一对话中把 App ID 和 App Secret 交给 Agent 代为保存。收到后，Agent 立即更新这个根目录 `.env`、免费校验 token，并只回复“已保存/失败”，不回显值、不将其带入命令、日志、输出或后续对话。群聊、公开链接、Issue 和截图中不得接收凭据。技术用户也可自行设置两个环境变量，或用 `--env-file` 指定自己的 `.env` 文件。

## 默认采集体验

用户只给公众号名称时：先搜索账号，展示名称、微信号和简介的少量候选；只有名称唯一匹配或用户明确选定后，才继续读取历史文章。之后用找到的 `wxid` 采集，避免让用户自行查原始 ID。

默认只采集最近 1 篇文章的正文，不取互动、图片或评论。按用户目标增量开启：

- 已知文章链接、只读正文：¥0.01。
- 只给公众号名称、最近 1 篇正文：最多 ¥0.16（账号搜索 ¥0.10 + 列表 ¥0.05 + 正文 ¥0.01）。
- 在上述基础上加完整互动：再加 ¥0.03。
- 评论、图片、更多文章、榜单或关键词搜索都是独立的可选范围，不能因为用户说“都要”就直接全开。

先用 `--dry-run` 生成清晰的中文成本清单，再用一句话确认：“本次最多花 ¥X，获取 Y；是否继续？”只有得到明确确认，才带 `--confirm-paid --max-cost` 执行。网络超时、非 JSON 和业务错误都停止，不重放可能已扣费的请求。

评论默认关闭；用户明确同意后也只输出一级、点赞不少于 10 的前 10 条，字段仅为正文与点赞数。静态图片也默认关闭，用户明确需要才加 `--download-images`。

## Agent 操作路由

- 配置/排障：读取 [首次使用引导](references/first-use.md)。脚本的 `status` 和 `setup` 分别用于无泄露的状态检查与本机隐藏输入；跨 Agent 的默认文件位置见该文件。
- 具体接口、字段、价格和频率：读取 [接口映射](references/cimidata-api.md)。
- 常用高层流程：使用 `collect`；它支持 `--wxid`、`--nickname` 或 `--article-url`，其中名称模式会先做一次受预算保护的账号定位。
- API 价格表未固化的网络热榜、搜狗临时链接、短链、封面单查和余额：先读取其当前 ShowDoc 页面，再用 `provider-call` 显式传入路径、JSON body 和价格；绝不猜测。

技术用户可运行：

```bash
python3 scripts/cimidata_wechat.py --help
python3 scripts/cimidata_wechat.py status
python3 scripts/cimidata_wechat.py setup
```

## 完成标准

完成一次普通用户任务时，报告：是否完成、文章/记录数、实际花费与上限、输出位置、是否采集评论/图片，以及可理解的失败原因与下一步。不要输出 App ID、App Secret、access token 或原始带身份信息的评论字段。
