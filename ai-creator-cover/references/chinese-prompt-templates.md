# 提示词编译规则（v2）

确认方案卡后，按本文件把方案编译成**一条段落式中文提示词**。结构 = 8 个固定模块按顺序拼装，皮肤模块照抄并代入档案值，变量模块按方案卡填空。

变量来源：`[品牌色]`、`[身份锁定描述]`、`[分类]`（标签集）取自 `profile.md`；其余取自方案卡。品牌色默认值 = 亮黄 #F5C518。

## 模块 1：画布与两区骨架（代入品牌色后照抄）

```text
制作一张 3:4 竖版中文视频封面，分辨率 1080x1440。封面分为上下两区：顶部约 25% 高度是纯黑色（#0A0A0A）平面信息栏，无纹理无渐变，所有文字只出现在信息栏内；信息栏下方到画面底部是照片区，照片装在一个[品牌色名称]（[品牌色色值]）圆角矩形描边框内，框线粗约画面宽度 2%，框左右各留 4% 黑色边距，照片填满框内。
```

## 模块 2：分类标签（填空：分类、品牌色）

```text
信息栏左上角放一个小型分类标签：一条[品牌色名称]短竖条，右侧紧跟白色粗体字"[分类]"，直接排在黑底上，整体占画面宽度约 16%，明显小于标题。
```

## 模块 3：标题文字（填空：标题、换色字、品牌色）

```text
信息栏内排主标题："[标题原文]"，使用超粗中文黑体（综艺标题字风格），字重最大，笔画紧凑，每行 4-7 个字，共 [1/2] 行，白色文字；其中"[换色字]"这几个字用[品牌色名称] [品牌色色值]，其余全部纯白，不倾斜、不放大、不另起一行。标题文字必须逐字准确渲染，不得出现错字、漏字、重复字或多余文字。画面中除分类标签和主标题外不出现任何其他文字。
```

## 模块 4：照片区摄影指导

**真人出镜模式**（填空：方案卡的全部表演参数，各项取自 `performance-library.md` 并已通过反重复检查）：

```text
照片区是一张真实抓拍感的摄影照片：参考图中的人物（[身份锁定描述]，保持五官、发型、体型、年龄感完全一致），[景别：脸手特写/近景半身/中景膝上/全身情境]，[朝向：正面/3/4侧/侧面]，[机位：平视/低角度仰拍/轻微俯拍]，占框内高度约 80%。TA 正在[具体动作，来自动作大类：……]，表情是[表情]，像被抓拍到的真实瞬间而不是摆拍。穿[服装：简洁轻便的上衣，短袖/薄卫衣/衬衫优先，不臃肿，颜色与场景协调不抢标题焦点]。场景是[场景，来自场景库，不默认工作桌]，[光线描述，默认：现场光，浅景深，背景虚化]。整体是电影感调色，带轻微胶片颗粒，色彩真实丰富，不是棚拍海报光，不是渲染图。
```

**无人脸模式**（填空：主角物件、场景、光线）：

```text
照片区是一张真实抓拍感的摄影照片：画面主角是[主角物件，例如：一只手握着亮屏的手机，屏幕上是 AI 对话界面的局部]，近景特写，占框内约 80%。画面要有真实的人的痕迹（手、桌面、环境），像工作中随手拍下的瞬间。场景是[环境]，[光线描述，默认：暖色现场光，浅景深，背景虚化]。整体是电影感调色，带轻微胶片颗粒，色彩真实丰富，不是产品渲染图，不是素材库摆拍。
```

## 模块 5：证据物（填空：证据物）

```text
TA 手里/身边有[证据物及其状态，例如：一台亮屏的手机，屏幕上是 Claude 对话界面的局部]，作为画面里唯一的证据物件，真实可信，在 TA 的[手势/视线]方向。
```

有用户素材图时改为：以图2/图3 作为证据物内容来源，只取最有证据感的一处局部，以真实物件形式出现（手机屏上、显示器一角），不悬浮。无人脸模式下，主角物件本身就是证据物，本模块并入模块 4，不重复描述。

## 模块 6：突破框（代入主体后照抄）

```text
[人物的头顶或抬起的手／无人脸模式：主角物件的上缘，如手机顶部、手指]越过[品牌色名称]框上沿，伸进黑色信息栏区域，轻微压住标题最下沿的笔画但不影响阅读，形成照片在框内、主体在框前的三层深度。
```

## 模块 7：停留点（可选，至多一个）

```text
一个[品牌色名称]手绘箭头从[起点]指向[证据物/换色字]。
```

或白色手绘圈注圈住证据物关键处。方案卡里没有就整段省略。

## 模块 8：禁止项（逐字照抄）

```text
禁止：REC 标识、红色录制点、红色边框；文字压在照片上；完整软件界面、任务清单、多个 UI 面板、底部信息条；多组大号彩色字互相抢焦点；棚拍硬光、科幻粒子、全息特效、海报渲染感；严肃证件照表情。
```

## 5 个证据预设

访谈第二轮给建议时，按选题就近取用。预设**只决定证据物方向和信息重心**，不含任何姿势、表情、场景、光线——这些表演参数一律从 `performance-library.md` 按主题映射 + 反重复规则另行选取，二者自由组合。无人脸模式下，证据物升级为画面主角。

### A. 发现/推荐
适合：工具推荐、新功能、"这个 AI 太强了"。
证据：亮屏手机或屏幕一角上的工具界面局部，只取一处最有"哇"感的关键区域。信息重心：让人好奇这是什么工具。

### B. 教程演示
适合：步骤教学、工作流、提示词写法。
证据：一个大输入框、单个结果卡或正在进行的操作画面。信息重心：看起来跟着做就能会。

### C. 对比反差
适合：AI vs 人工、旧方法 vs 新方法。
证据：两个真实物件并置（手写纸 vs 屏幕；旧界面 vs 新界面），新的一侧更亮。保持单一真实场景，不做分屏拼贴。信息重心：差距一眼可见。

### D. 认知观点
适合："AI 会取代谁""普通人该怎么办"。
证据：可以没有，或一个弱道具（合上的笔记本电脑、手机扣在桌上）。信息重心：人物情绪本身就是封面，标题承担全部信息。

### E. 课程/资料包
适合：训练营、合集、资料包。
证据：平板/手机上的课程目录局部，或一摞打印资料、实体物料。信息重心：拿到手里的获得感。

## 文字保真重试策略

生图后标题文字出错时按顺序降级重试（同方案最多 3 次）：

1. 标题缩到 ≤10 字，换色字减到 ≤2 字
2. 提示词中把标题原文用引号重复两遍，并加"逐字准确渲染每一个汉字"
3. 把两行标题改成一行短句

仍失败：建议用户换更短标题，或拆掉生僻字。
